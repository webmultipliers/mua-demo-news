## Local development

```bash
composer install
npm install
npm run build
```

For interactive mobile development (requires Xcode on macOS or Android Studio):

```bash
php artisan native:install
php artisan native:run
```

For iOS hot-reload via the Jump app:

```bash
php artisan native:jump
```

Then scan the QR code with the NativePHP Jump iOS app.
